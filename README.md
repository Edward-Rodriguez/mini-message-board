# mini-message-board

A mini mock message board built with express.

**Live Demo:** [https://mini-message-board-4yik.onrender.com/](https://mini-message-board-4yik.onrender.com/)

## Features

- View messages
- Add new messages

## Tech

- Node.js
- Express
- EJS
- CSS

## Deployment

- Render

## Run Locally

npm install
npm run dev

Then open <http://localhost:3001>
